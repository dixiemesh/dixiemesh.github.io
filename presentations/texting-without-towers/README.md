# LoRa Mesh Networking for Amateur Radio Operators

Interactive 20-slide HTML presentation for Dixie Amateur Radio Club.

## Present

Open `index.html` in a modern browser.

- `←` / `→` or Page Up / Page Down: navigate
- `N`: speaker notes
- `O`: slide overview
- `F`: fullscreen
- Swipe on touch devices

The waterfall slide includes a synthesized illustrative chirp. The mesh-basics slide includes an animated packet relay.
